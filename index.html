Gestos incluidos

  • Palma abierta (Open_Palm): muestra “¡Hola!”
  • Puño cerrado (Closed_Fist): pausa el contador de demostración.
  • Victoria / V (Victory): muestra una confirmación.
  • Pulgar arriba (Thumb_Up): suma un punto al marcador.

Marcador: 0 puntos. Las acciones se ejecutan al cambiar de gesto para evitar repetirlas en cada fotograma.

El procesamiento se realiza en el navegador con el modelo de MediaPipe. Se necesita conexión a Internet para cargar la biblioteca y el modelo. La cámara solo se activa después de pulsar el botón.
